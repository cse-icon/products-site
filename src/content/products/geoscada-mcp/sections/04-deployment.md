---
title: Runs on the Engineer's Machine
description: >-
  A single signed executable runs beside the engineer's assistant on Windows.
  It opens no network port, so there is no server to expose or secure.
icon: deploy
features:
  - title: Ten-Minute Setup
    description: Unzip the signed executable, create an ODBC data source, and point your assistant at it. No runtime to install.
  - title: Claude Desktop Extension
    description: Install as a Claude Desktop extension, which asks for the data source in a form.
  - title: Install Check
    description: A built-in check finds the usual first-run problems, such as a missing driver, the wrong data source, or an unreachable server, before you connect.
  - title: One Entry per System
    description: Add one server entry for each Geo SCADA system, so point Ids from different systems are never confused.
  - title: Redundancy Aware
    description: Reports which node it is connected to and that node's main or standby role.
  - title: Offline Licensing
    description: One licence per machine, dated or perpetual, checked on the machine itself. Nothing calls home.
  - title: What You Need
    description: Verified on Geo SCADA 2023. Needs the Data Access components installed with ViewX and a read-only Geo SCADA account.
  - title: Signed and Verifiable
    description: The executable and its ODBC component are code-signed by CSE ICON and timestamped.
---
