---
title: One question, one answer
description: >-
  The assistant does the chain of lookups an engineer would do by hand, and
  returns a verdict with evidence.
icon: sparkles
features:
  - title: Why is this point stale?
    description: Checks logging, quality, comms, sibling points, and recent changes, then tells you which one it is.
  - title: Why didn't this alarm fire?
    description: Finds the disable, suppression, or out-of-service state that kept the alarm quiet.
  - title: Are comms to blame?
    description: Follows a point back to its scanner and tells one broken device from one broken tag.
  - title: Is the server healthy?
    description: Server state, redundancy role, drivers, and licence capacity in a single answer.
  - title: Whose gap is it?
    description: Shows whether Geo SCADA held the data, so a gap downstream gets blamed on the right system.
  - title: Packaged runbooks
    description: Ready-made prompts for failing-point triage, incident timelines, and a start-of-shift health check.
---
