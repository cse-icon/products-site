---
title: One Question, One Answer
description: >-
  Composed diagnostics do the chain of lookups an engineer would otherwise do by
  hand, and return a verdict with the evidence behind it.
icon: sparkles
features:
  - title: Why Is This Point Stale?
    description: Checks history logging, retained data, quality, service state, sibling points on the same device, and recent operator and config activity.
  - title: Why Didn't This Alarm Fire?
    description: Reports which alarm bands are genuinely armed, plus any disable, suppression, or out-of-service state that kept the alarm quiet.
  - title: Are Comms to Blame?
    description: Follows a point to the scanner or subscription that feeds it, and separates one broken device from one broken tag.
  - title: Is the Server Healthy?
    description: Per-server state and redundancy role, driver modules, the recent mix of event severities, and licence capacity, in one call.
  - title: Whose Gap Is It?
    description: Shows whether Geo SCADA held data across a window, so a gap seen downstream is attributed to the right side.
  - title: Which Points Can Really Alarm?
    description: An estate-wide census of points that can actually raise an alarm, and those whose limits look right but stay silent.
  - title: Packaged Runbooks
    description: Ready-made prompts for failing-point triage, incident timelines, a start-of-shift health check, and chasing a downstream gap.
  - title: Works With Your Assistant
    description: Claude Desktop, Claude Code, Cursor, VS Code — any MCP client.
---
