  - title: Preflight Checks
    description: Checks the host against every requirement, including network reach, permissions, and the licence, before anything is scheduled.
  - title: Live Dashboard
    description: See every source's status, which ones are catching up, and any batch that needs a decision.
  - title: Alerts Where You Work
    description: Health changes post to Microsoft Teams, Slack, or any webhook, including the all-clear.
  - title: Support in One Click
    description: Logs from every source and stage, merged and followed live, plus a downloadable support bundle that never contains secrets.
  - title: Runs Beside the Historian
    description: Lives on its own Windows Server host, on premises or in Azure, so publishing can never disturb data collection.
  - title: What You Need
    description: Canary Historian 26.5 or later, network access to its gRPC API, and an Azure Blob Storage container.
