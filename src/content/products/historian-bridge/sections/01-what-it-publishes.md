---
title: Historian Data, Ready for Analytics
description: >-
  Point it at a Canary view and it publishes tables your data team can query —
  readings, metadata, and events — with no code to write.
icon: database
features:
  - title: Raw Readings
    description: Every value, timestamp, and quality code, one row per reading.
  - title: Server-Side Aggregates
    description: Or let Canary compute them, such as 10-minute time-weighted averages, and publish one row per interval.
  - title: Tag Metadata
    description: A daily snapshot of every tag and all its Canary properties, with the ones you choose promoted to columns.
  - title: Events
    description: Canary Calcs & Events occurrences, with open events kept current until they close.
  - title: Quality Preserved
    description: Bad and uncertain points are published with their quality codes, so you decide what to filter.
  - title: Configuration, Not Code
    description: Adding a source is a Canary view, a scoped token, and one configuration entry. Each source gets its own tables.
---
